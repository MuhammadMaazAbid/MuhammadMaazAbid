## The person behind the code

I'm Maaz, a Computer Science undergraduate based in Islamabad, Pakistan.

I build across web, mobile, and backend systems. My experience spans independent client delivery, startup prototypes, and academic projects. I use AI coding tools as part of my development workflow, alongside requirements gathering, implementation, debugging, and feedback.

Working in growth has also put me in conversations with business owners. Those conversations help me understand the problems a product needs to solve.

**My throughline: understand the need, build a working version, and refine it with feedback.**
